# LORDNUTRI Revendedores — 0.7.0 FREE CANVAS

A 0.7.0 muda o editor da Landing Page para um modelo **base segura + camadas livres**.

A página React original continua responsável por responsividade, checkout, simulador, Asaas, kits e estrutura. O editor pode alterar os textos originais e, quando você quer liberdade visual, pode **duplicar um texto ou imagem como camada livre**.

## No BKO → Conteúdo → Landing Page

- clique em texto original para editar a copy;
- clique em texto ou imagem e use **Duplicar** para transformar a cópia em camada livre;
- use **＋ Texto** para criar um texto novo;
- use **＋ Imagem** para criar uma nova camada de imagem;
- arraste uma camada pelo `✥`;
- redimensione pelo `↘`;
- use Desktop / Tablet / Celular para gravar posições diferentes em cada breakpoint;
- use Desfazer / Refazer antes de publicar.

Checkout, simulador e componentes funcionais não são movidos nem reescritos pelo Free Canvas.
