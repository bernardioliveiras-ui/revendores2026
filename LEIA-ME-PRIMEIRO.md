# LEIA-ME PRIMEIRO

Esta é a nova versão do MIX10 PRO feita para **banco novo** e **Hostinger**.

1. Crie um MySQL novo e importe `database/schema.sql`.
2. Configure as variáveis de `.env.example` no painel da Hostinger.
3. Coloque sua VSL final em `public/videos/vsl-mix10.mp4`.
4. Faça o deploy com Node 22: `npm ci`, `npm run build`, `npm start`.
5. Comece com Asaas sandbox e siga `HOSTINGER-DEPLOY.md` para testar o fluxo completo.

Operação diária do BKO: `BKO-OPERACAO.md`.
