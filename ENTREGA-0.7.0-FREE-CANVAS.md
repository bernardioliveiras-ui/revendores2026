# LORDNUTRI 0.7.0 — FREE CANVAS

Esta versão troca o antigo page builder estrutural por uma arquitetura híbrida mais estável:

- a landing React original não é reordenada nem reescrita pelo editor;
- textos originais continuam editáveis;
- qualquer texto ou imagem original pode ser duplicado como **camada livre**;
- camadas livres podem ser arrastadas, redimensionadas, duplicadas, excluídas e ordenadas;
- é possível criar um novo texto ou uma nova imagem;
- posição e largura são salvas separadamente para desktop, tablet e celular;
- o texto `MIX10 PRO` e `LORD NUTRI` continua reconstruindo a identidade visual da marca;
- checkout, Asaas, simulador, grids e componentes funcionais permanecem na estrutura React original;
- processo ANVISA preservado exatamente: `2535115572620267`.

## Uso

1. Abra BKO → Conteúdo → Landing Page.
2. Clique em um texto ou imagem original.
3. Use **Duplicar** para criar uma camada livre.
4. Na prévia, arraste pelo `✥` e redimensione pelo `↘`.
5. Troque entre Desktop / Tablet / Celular para ajustar cada breakpoint.
6. Salve o rascunho e publique quando estiver satisfeito.

Novo texto e nova imagem podem ser criados pelos botões **＋ Texto** e **＋ Imagem**.
