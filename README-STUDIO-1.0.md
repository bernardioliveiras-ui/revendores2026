# Como usar o Studio LP

1. Entre no BKO e abra **Studio LP**.
2. Na primeira abertura, a landing atual é importada como template do Studio.
3. Clique em qualquer elemento para selecionar. Dê duplo clique em texto para editar direto no canvas.
4. Use o painel da direita para fonte, tamanho, cor, espaçamento, largura, flex/grid e responsividade.
5. Use a lista **Camadas** para reorganizar elementos e seções por arrastar.
6. Para um posicionamento tipo Photoshop, ative **Posição livre**, depois segure **ALT** e arraste. Faça isso por breakpoint somente quando realmente precisar.
7. Clique em **Salvar** para manter como rascunho; **Publicar** coloca o documento do Studio no site.
8. **Publicar layout original** retorna o site público para a versão codificada, sem apagar seu rascunho do Studio.

Checkout/Asaas, simulador e os dados dinâmicos do Google aparecem com cadeado para evitar que uma edição visual quebre a operação.
