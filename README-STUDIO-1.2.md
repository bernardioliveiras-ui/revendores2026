# Studio Nested Flow 1.2

O editor trabalha em fluxo responsivo. A landing não usa coordenadas X/Y para montar o layout.

### Inserir dentro de um card

1. Clique no card desejado.
2. No painel direito, use **Adicionar dentro deste bloco**.
3. Escolha Texto, Destaque, Botão, Imagem ou Bloco.

### Mover entre cards

1. Selecione o elemento.
2. Arraste-o sobre o card de destino.
3. Quando o card receber contorno verde tracejado, solte.

### Exemplo: R$ 10 mil/mês

Selecione o card desejado e clique em **+ Destaque**. O Studio cria o texto dentro do card, centralizado, dourado e responsivo. Depois você pode mudar conteúdo, tamanho, cor e espaçamento.

### Componentes protegidos

Checkout, simulador e avaliações dinâmicas são movidos como blocos completos. A lógica interna permanece protegida.
