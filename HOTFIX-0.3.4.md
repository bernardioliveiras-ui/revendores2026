# LORDNUTRI Revendedores — 0.3.4

## Copy institucional
- Corrigido o bloco LORD NUTRI para eliminar a frase incorreta/repetitiva.
- Nova hierarquia: “E quem está por trás de tudo isso?” → LORD NUTRI → marca por trás do programa de revendedores MIX10 PRO.
- O bloco institucional ignora overrides legados da versão 0.3.x para remover a copy antiga que já havia sido publicada incorretamente.

## Pessoas integradas ao fundo
- As duas cenas com pessoas deixaram de funcionar visualmente como cards/fotos em destaque.
- Opacidade, saturação, brilho, máscaras e gradientes foram reduzidos para as pessoas funcionarem como ambientação editorial, no espírito do PDF de referência.
- A animação de flutuação foi removida dessas duas imagens para não disputar atenção com a copy.
- Desktop e celular têm composições próprias.

## Conteúdo / BKO — layout protegido
- As chaves de edição agora são estáveis por seção, evitando que a inclusão de uma nova seção faça um texto salvo aparecer em outro lugar da LP.
- O runtime só aplica conteúdo a folhas de texto ou a formatos ricos explicitamente seguros (marca e quebra de linha).
- Elementos compostos com `strong`, `span`, cards, grids ou outras estruturas não recebem mais substituição genérica de `textContent`.
- As classes CSS, ícones, grids e estrutura HTML não são salvos pelo CMS.
- Mantida compatibilidade com overrides 0.3.x fora do bloco institucional LORD NUTRI.
- Imagens continuam editáveis separadamente.
