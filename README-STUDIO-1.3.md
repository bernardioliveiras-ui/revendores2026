# Studio Safe Flow 1.3

O editor visual trabalha em fluxo responsivo e protege componentes funcionais críticos.

- Edite textos, imagens, cards, cores, tamanhos e espaçamentos.
- Duplique e exclua elementos visuais comuns.
- Checkout Asaas, simulador e avaliações Google aparecem com cadeado e não podem ser removidos/desmontados.
- Se um rascunho antigo estiver sem esses componentes, o Studio tenta reparar automaticamente pela landing-base.
- O servidor bloqueia publicação quando um componente crítico está ausente ou duplicado.
- A página pública ainda possui fallback de recuperação para evitar perda do checkout por versões antigas.
