# Banco MySQL — MIX10 PRO

Este projeto usa um banco MySQL novo. No hPanel da Hostinger, crie o banco e o usuário, abra o phpMyAdmin e importe `database/schema.sql` uma única vez.

Depois configure `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_NAME`, `DATABASE_USER` e `DATABASE_PASSWORD` nas variáveis da aplicação Node.js. Não envie essas credenciais para o GitHub.
