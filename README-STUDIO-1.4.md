# Studio Parity 1.4

O Studio LP foi reduzido para dois modos de edição: **Computador** e **Celular**.

## Computador

O preview é renderizado em uma viewport interna real de 1366 px. O BKO apenas escala visualmente o iframe para caber na área central. Assim, o CSS responsivo dentro do preview não passa a usar breakpoints menores só porque o painel do BKO é estreito.

## Celular

O preview usa 390 px. Os estilos específicos do Studio para celular são publicados em `@media(max-width:700px)`, o mesmo corte principal usado pela landing base.

## Boas-vindas do Portal do Revendedor

Acesse **BKO → Conteúdo → Mídia**. Em “Vídeo da aba Boas Vindas” você pode colar YouTube, Vimeo ou MP4 HTTPS, ou enviar vídeo curto MP4/WebM/Ogg. Depois clique em **Publicar**.
